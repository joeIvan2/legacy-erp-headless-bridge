# Screenshot Policy

這個資料夾包含兩張公開展示的真實截圖。它們使用「現金銷售客戶」示範資料，沒有個人客戶資訊，並保留相同單據內容，目的是證明桌面 EXE 與真實 Web 頁面可以逐欄比對。

目前檔名：

- `original-erp.png`：原版 Delphi 32-bit 桌面 EXE 銷貨單畫面
- `web-sale-voucher.png`：Flask／HTML／CSS／JavaScript 真實網頁畫面

兩張圖片依使用者要求保持原始像素，不做遮蔽、重繪或 AI 修復。

## 未來其他截圖的檢查項目

- ERP 帳號、Windows 帳號與任何密碼提示
- 公司代號、公司名稱與授權資訊
- 客戶 ID、客戶名稱、聯絡資料與統一編號
- 銷貨單號、日期、品號、品名、價格與備註
- 內網 IP、主機名稱、瀏覽器網址與查詢參數
- Discord server、channel、user、token 或 webhook 資訊
- 其他可由畫面交叉識別真實交易的資訊

## 保留內容

- 視窗層級、欄位布局與操作結構
- 經過虛構替換的示範資料
- 能比較桌面版與 Web 版資訊架構的部分

目前兩張「現金銷售客戶」對照圖已由使用者確認沒有個資。若未來加入其他正式客戶截圖，必須先依上列項目檢查；若曾誤提交不適合公開的影像，也需處理舊 Git 歷史，不能只刪除最新版本。
